Import mã ICD
File phải có định dạng Excel với các cột: Mã ICD, Tên bệnh, Mô tả, Nhóm bệnh
Hướng dẫn:
  • Tải mẫu file bằng nút "Xuất mẫu"
  • Điền dữ liệu theo mẫu
  • Mã ICD: Mã bệnh theo chuẩn ICD
  • Tên bệnh: Tên đầy đủ của bệnh
  • Mô tả: Mô tả chi tiết về bệnh (tùy chọn)
  • Nhóm bệnh: Nhóm phân loại bệnh (tùy chọn)
  • Upload file để import
